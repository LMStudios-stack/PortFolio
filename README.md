# 🚀 3D Developer Portfolio Website (React + TypeScript + Three.js)[cite: 1]

If you’re a developer looking for a **portfolio template** that feels premium, interactive, and memorable—this repo is for you.[cite: 1]

## 🚀 Getting Started[cite: 1]

### 1) Clone[cite: 1]

```bash
git clone [https://github.com/red1-for-hek/portfolio-website.git](https://github.com/red1-for-hek/portfolio-website.git)
cd portfolio-website
```[cite: 1]

### 2) Install[cite: 1]

```bash
npm install
```[cite: 1]

### 3) Run locally[cite: 1]

```bash
npm run dev
```[cite: 1]

### 4) Build[cite: 1]

```bash
npm run build
```[cite: 1]
